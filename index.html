This is a one-time setup. Once done, everyone who opens the URL will share the same live data — rosters, results, and leaderboard.
Step-by-step instructions
1
Create a free Supabase account
Go to supabase.com → click "Start your project" → sign up with GitHub or email. It's free, no credit card needed.
2
Create a new project
Click "New project" → name it march-matness → pick any region → set a database password (save it somewhere) → click "Create new project". Wait ~1 minute for it to spin up.
3
Create the two database tables
In your project, click SQL Editor in the left sidebar → click "New query" → paste this entire block and click Run:
create table participants ( id uuid default gen_random_uuid() primary key, name text not null, roster jsonb default '{}'::jsonb, created_at timestamptz default now() ); create table results ( id uuid default gen_random_uuid() primary key, weight int not null, wrestler_name text not null, bracket text not null, round text not null, result_type text not null default 'decision', placement_pts numeric default 0, source text default 'manual', created_at timestamptz default now() ); alter table participants enable row level security; alter table results enable row level security; create policy "Public read" on participants for select using (true); create policy "Public insert" on participants for insert with check (true); create policy "Public update" on participants for update using (true); create policy "Public delete" on participants for delete using (true); create policy "Public read" on results for select using (true); create policy "Public insert" on results for insert with check (true); create policy "Public delete" on results for delete using (true);
4
Get your API keys
Click Project Settings (gear icon) → API → copy two things:
• Project URL — looks like https://abcxyz.supabase.co
• anon public key — a long string starting with eyJ...
5
Paste them below and save

Share the app
Once you've completed setup above, host the app for free on GitHub Pages so anyone can open it. The credentials are saved in each user's browser automatically once you share the URL.
1
Download this HTML file — use the download button below.
2
Open the file in a text editor (Notepad on Windows, TextEdit on Mac). Find the line near the top that says supabaseUrl: localStorage.getItem('mm_url') || '' and replace the two empty '' values with your actual URL and key so they're pre-filled for everyone:

supabaseUrl: 'https://abcxyz.supabase.co'
supabaseKey: 'eyJ...'
3
Go to github.com → create a free account → click "+" → New repository → name it march-matness → set it to Public → click "Create repository".
4
Upload the file → on your new repo page click "uploading an existing file" → drag in your index.html → click "Commit changes".
5
Enable GitHub Pages → click Settings → Pages (left sidebar) → under "Source" select "Deploy from a branch" → branch: main, folder: / (root) → Save. Wait ~1 minute.
6
Your URL will be https://YOURUSERNAME.github.io/march-matness — share this with your pool participants!
